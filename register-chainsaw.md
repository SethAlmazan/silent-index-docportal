# Register Chainsaw

**Location:** Project Homepage > Chainsaw Registration > Register Chainsaw

---

## Functional Description

The Register Chainsaw feature allows an authorized user to add a new chainsaw registration record into the Chainventory system. The user enters the owner information, chainsaw details, registration details, permit dates, and related information needed for record management. This feature helps organize chainsaw registration data in one centralized system.

---

## Use Case Scenario

| Field          | Description                                                                                                                                                                                                                                                                                                                                          |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Use Case ID    | UC-REG-01                                                                                                                                                                                                                                                                                                                                            |
| Use Case Name  | Register Chainsaw                                                                                                                                                                                                                                                                                                                                    |
| Actor          | Authorized User                                                                                                                                                                                                                                                                                                                                      |
| Precondition   | The user is logged in to the Chainventory system.                                                                                                                                                                                                                                                                                                    |
| Trigger        | The user opens the Chainsaw Registration page.                                                                                                                                                                                                                                                                                                       |
| Main Flow      | 1. The user opens the chainsaw registration form. <br> 2. The user enters the owner details, chainsaw information, registration date, expiry date, and status of issuance. <br> 3. The user submits the form. <br> 4. The system saves the chainsaw registration record. <br> 5. The system redirects or updates the user after the record is saved. |
| Alternate Flow | If required information is missing or an error occurs, the system does not save the record and displays an error message.                                                                                                                                                                                                                            |
| Postcondition  | A new chainsaw registration record is added to the system.                                                                                                                                                                                                                                                                                           |
