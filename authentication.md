# Authentication

**Location:** Project Homepage > Authentication

---

## Functional Description

The Authentication module allows authorized users to access the Chainventory system using their registered email and password. It helps ensure that only users with valid accounts can enter the system and manage chainsaw registration records.

---

## Use Case Scenario

| Field | Description |
|---|---|
| Use Case ID | UC-AUTH-01 |
| Use Case Name | User Login |
| Actor | Authorized User |
| Precondition | The user already has an account. |
| Trigger | The user opens the login page. |
| Main Flow | 1. The user enters an email and password. <br> 2. The user clicks the login button. <br> 3. The system checks the account credentials. <br> 4. The system redirects the user to the dashboard after successful login. |
| Alternate Flow | If the email or password is incorrect, the system displays an error message. |
| Postcondition | The user is successfully logged in and can access the system. |
