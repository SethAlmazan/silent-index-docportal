# View Reports and Analytics

**Location:** Project Homepage > Reports > View Reports and Analytics

---

## Functional Description

The View Reports and Analytics feature allows an authorized user to view summarized information about chainsaw registration records. The reports page displays important data such as total registrations, active permits, expired permits, and other record-based summaries. This feature helps users review the overall status of chainsaw registration records in the system.
